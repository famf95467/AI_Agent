# Контент-агент

## Установка
1. Python 3.12 (для 3.15 нет готовых сборок библиотек) и ffmpeg: `winget install Gyan.FFmpeg`, перезапусти консоль.
2. `py -3.12 -m venv venv`, затем `venv\Scripts\python -m pip install -r requirements.txt`.

## Порядок работы
1. В config.yaml укажи `video_path`, `chat_path`, `chat_offset_sec`, `webcam_region`.
2. `venv\Scripts\python main.py` - расшифровка, поиск моментов, файл `output/candidates.md` (30 кандидатов).
   Расшифровка кэшируется в `work/`, повторные запуски быстрые.
3. Открой candidates.md, выбери номера и запусти: `venv\Scripts\python main.py --pick 3,7,12`.
   Для всех кандидатов сразу: `--pick all`. Клипы появятся в `output/` под именами `rank_{номер}_{начало}-{конец}.mp4`. Раскладку можно подбирать, меняя config.yaml и запуская --pick заново.
4. Чтобы клипы делались сразу из лучших `clips_count` кандидатов: `auto_top_n: true`.

## Как вырезать тест на 30 минут (с 30-й минуты)
`ffmpeg -ss 1800 -i "C:/Sources/Streams/Stream.mp4" -t 1800 -c copy "C:/Sources/Streams/test30.mp4"`
Для такого отрывка `chat_offset_sec: -1800`. Если отрывок с самого начала записи: `0`.

## Границы клипа
Клип = пик (громкость + чат) минус `preroll_sec` плюс `postroll_sec`; границы сдвигаются к ближайшей фразе или паузе
в расшифровке (до 4 сек), тишина по краям (нет речи и тихо) обрезается, длина остаётся между `clip_min_sec` и `clip_max_sec`.
Если не влезает в `clip_max_sec`, сначала урезается postroll (не меньше 3 сек), потом preroll (не меньше 8 сек).
Если речи в клипе меньше `min_speech_coverage`, кандидат заменяется следующим по оценке.

## Чат без данных на части записи
Покрытие чата берётся из файла (поля video.start/end, плюс `chat_offset_sec`), иначе по последнему сообщению.
Для кандидатов вне покрытия чат не учитывается: оценка считается по остальным сигналам (делится на сумму их весов),
в начале candidates.md есть предупреждение «Чат покрывает только ...».

## Цикл оценок и подбор весов
1. После нарезки в `ratings.csv` (рядом с main.py) добавляются клипы: видео, номер, время, значения сигналов (0..1) и пустая колонка `rating`.
   Таблица с разделителем `;` и запятой в числах открывается в русском Excel. Закрывай файл перед запуском программы.
2. Поставь `rating`: 0 - ни о чём, 1 - средне, 2 - хорошо. Заголовок и другие колонки не меняй.
   Повторная нарезка тех же моментов (пересечение интервалов от 50% длительности) обновляет строку и сохраняет оценку.
3. `venv\Scripts\python main.py --learn`: нужно не меньше `learn_min_rated` (30) оценённых клипов с данными чата
   (клипы без чата в обучение не берутся). Подбор: гребневая линейная регрессия на numpy, проверка на отложенных данных.
   Если все оценки почти одинаковые или связь с сигналами слабая (корреляция при проверке меньше 0.25), веса не предлагаются.
4. Результат: старые и новые веса в консоли и файл `suggested_weights.yaml`. `config.yaml` программа не меняет: перенеси веса сам.

## Области webcam_region и game_region
Задаются в процентах кадра (`"27.7%"`, не зависят от разрешения) или в пикселях исходного видео (число без кавычек).
Как найти значения: сохрани кадр `ffmpeg -ss 600 -i "C:/Sources/Streams/Stream.mp4" -frames:v 1 frame.png`,
открой в Paint (координаты курсора внизу слева), найди левый верхний и правый нижний углы области.
Процент = пиксели / размер кадра * 100. `region_inset_px: 4` срезает 4 пикселя внутрь от границ каждой области.

## Превью раскладки (обязательно перед нарезкой)
`venv\Scripts\python main.py --preview` сохраняет `output/preview.png`: слева исходный кадр с рамками
(красная - вебкамера, зелёная - игра), справа итоговый вертикальный кадр (жёлтая линия - граница частей).
Программа спросит «да/нет». Пока раскладка не подтверждена, нарезка (`--pick` или `auto_top_n`) не начнётся.
Если ты не менял области, отступ и режимы fit, повторно спрашивать не будет, но preview.png обновится.

## fit-режимы
- `webcam_fit` / `game_fit: crop`: часть кадра заполняется целиком, лишнее срезается по краям, центр области остаётся в центре.
- `pad`: ширина 1080, пустое место заполняет размытый фон (для игры - целиком, без обрезки).
